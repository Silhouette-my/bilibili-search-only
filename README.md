## 📖 bilibili-FOCUS

看 Bilibili 总是因为大数据推送分心？
相关推荐一看就停不下来？  

这个插件帮你屏蔽掉冗余的推荐内容，让你专注于视频和搜索本身，并支持在指定时段或条件下强制保持开启。

---

### 🔥 v3.4 升级

- **播放页推荐区改为直接隐藏**
  - 原“播放页遮罩”调整为隐藏整个相关推荐区域，不再遮住标题、简介、评论等其他内容
  - 页面滚动和播放器操作保持正常，并继续与“自动关闭连播及隐藏结束推荐”独立控制

- **按规则自动开启所选功能**
  - 可分别选择站点封锁、全局专注重定向、隐藏播放页相关推荐、关闭连播和搜索页遮罩
  - 固定时段、专注倒计时或累计使用超时触发后，自动开启已选择的功能
  - 严格模式下禁止从插件面板关闭并自动修复绕过写入；非严格模式允许仅在本次规则期间临时调整
  - 旧配置升级后默认继续选择“站点封锁”，无需迁移原有开关偏好

### v3.3 播放器升级

- **播放器自定义快捷键**
  - 为播放、快退/快进、静音、倍速、字幕、弹幕和两种全屏方式自由录制单键或组合键
  - 使用物理键位保存配置，重复绑定自动改绑；默认开启但不预设按键，升级后不会改变现有操作
  - 仅在普通视频页且播放器悬停、网页全屏或系统全屏时生效，输入与编辑区域始终放行

- **安全、兼容与反馈**
  - 只执行固定动作目录，不接受任意 CSS 选择器、脚本或消息配置，也不增加扩展权限
  - 原生视频能力优先，播放器控件缺失、无字幕或需要登录时会安全失败并显示轻量提示
  - 配置 schema 升级到 v2，设置保存、同步重载、并发冲突与 BFCache 生命周期均纳入回归测试

### v3.2 基础升级

- **后台成为唯一策略权威**
  - 顶层导航和 SPA History API 路由变化统一由后台复核
  - 站点封锁切换到扩展自有页面，不再把共享页面 DOM 当作强制边界
  - 控制面板、设置页和封锁页通过版本化消息协议提交命令

- **状态与生命周期收口**
  - 新增纯状态求值核心、版本化存储迁移和精确状态边界调度
  - 播放页与搜索页观察器缩小到目标节点，并在页面冻结/恢复时正确停启
  - 旧配置可幂等迁移，未来 schema 不会被旧版本静默降级

- **可复现发布**
  - 运行时保持零第三方依赖
  - 严格 allowlist 打包、固定文件顺序与时间戳，并生成 SHA-256
  - CI 覆盖语法、单元测试、运行时引用闭包和隔离 MV3 浏览器 smoke

### ✨ 功能介绍
- **全局专注重定向**
  - 自动拦截容易让人分心的首页、动态流等页面，直接重定向到纯净搜索页
  - 内置智能白名单，安全放行视频播放、番剧详情、合集/播放列表、直播间、个人空间、消息中心、账号设置等核心功能

- **站点封锁**
  - 可在固定时段、专注倒计时、累计使用超时等条件触发时，将顶层 Bilibili 标签页切换到扩展自有封锁页
  - 可与其他去干扰功能一起设置为规则触发后自动开启
  
- **搜索页优化**  
  - 使用 [https://search.bilibili.com](https://search.bilibili.com) 获得纯净的搜索框页面  
  - 隐藏顶部导航栏和个性推送  
  - 搜索框居中显示，界面简洁无干扰  

- **播放页优化**  
  - 可隐藏播放页整个相关推荐区域，同时保留标题、简介、评论和正常页面滚动
  - 自动关闭播放页的「自动连播」，并隐藏播放结束后的相关推荐
  - 可为播放、±5 秒、静音、倍速、字幕、弹幕和全屏动作录制自定义快捷键

- **锁定策略**
  - 支持每周固定时段、专注倒计时、每日累计使用超时三类条件
  - 可分别设置每类条件是否触发锁定规则
  - 可选择规则触发时自动开启站点封锁、全局专注重定向、隐藏播放页相关推荐、自动关闭连播并隐藏结束推荐、搜索页遮罩
  - 支持严格模式，开启后命中条件时无法从弹窗关闭已锁定功能
  - 关闭严格模式后，命中条件时仍会自动开启所选功能，但允许在弹窗更改

- **控制面板**  
  - 提供锁定状态、站点封锁与四项去干扰开关，以及专注倒计时快捷操作
  - 详细规则通过独立设置页维护，避免弹窗过度拥挤
  - 弹窗与设置页统一重绘，支持浅色/深色主题和更紧凑的专注式布局

### 🛠️ 安装方法

1. 下载或克隆本仓库：
   ```bash
   git clone https://github.com/Silhouette-my/bilibili-FOCUS.git
   ```
2. 使用 Chrome 102 或更高版本，进入扩展管理页面：
   ```
   chrome://extensions
   ```
3. 打开右上角 **开发者模式**  
4. 点击 **加载已解压的扩展程序**  
5. 选择本仓库目录，即可启用插件

### ✅ 开发验证

常规验证与打包只使用 Node.js 内置模块，无需安装依赖：

```bash
npm run validate
npm run check
npm test
npm run package
```

`npm run package` 仅打包显式 allowlist 中、且能从 manifest 和运行时引用图到达的文件，
输出 `dist/bilibili-focus-<version>.zip` 与对应 `.sha256`。

真实 MV3 smoke 需要 Playwright，仅作为固定版本的 CI/开发依赖临时安装，不会进入扩展包：

```bash
npm install --ignore-scripts --no-audit --no-fund --no-save --no-package-lock playwright@1.55.0
npx playwright install chromium
npm run test:mv3
```

浏览器 smoke 使用本地响应满足所有 Bilibili HTTP(S) 文档，并阻止其他外部 HTTP(S)
请求；生产 Bilibili 请求计数必须为 0。

隐私、权限和漏洞报告流程分别见 [PRIVACY.md](PRIVACY.md)、
[PERMISSIONS.md](PERMISSIONS.md) 与 [SECURITY.md](SECURITY.md)。

### 🚀 使用说明

- 安装完成后，浏览器工具栏会出现插件图标  
- 点击图标打开控制面板，可以自由切换功能开关  
- 需要长期约束时，可在设置页配置访问限制条件、严格模式、固定时段、每日累计时长、界面主题和播放器快捷键
- 快捷键只在普通视频页的播放器悬停、网页全屏或系统全屏时生效；浏览器或操作系统保留组合键可能不可用
- 在搜索页和播放页体验纯净界面，避免推荐干扰
